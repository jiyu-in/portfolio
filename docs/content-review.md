- 목록·상세 페이지에 참고 이미지 표기를 추가했습니다. 실제 UI 캡처로 교체한 뒤 `imageKind: screenshot`으로 변경하면 참고 이미지 표기가 사라집니다.

- `imageAlt`에 화면의 내용을 설명하고, 필요한 경우 `imageCaption`에 공개 범위·설명 등을 입력합니다. 비공개 정보는 이미지를 올리기 전에 가립니다.
- 프로젝트별 입력은 `src/data/projectData.js`의 `selection` 항목에 추가할 수 있습니다. 해당 항목의 값이 기본값을 덮어씁니다.
